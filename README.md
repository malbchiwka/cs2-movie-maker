# CS2 Movie Maker

Десктопное приложение для Windows: создание готового мувика (`.mp4`) из демо-записи Counter-Strike 2 (`.dem`) за пару кликов.

> **Безопасность (VAC):** Приложение **никогда** не модифицирует память мультиплеера и запускает `cs2.exe` исключительно с флагом `-insecure` (отключающим VAC) для локального воспроизведения демо-файлов.

---

## Возможности

1. **Быстрый парсинг `.dem` (< 1–2 сек на 30 раундов)** на базе Rust-движка `demoparser2`:
   - Drag & Drop `.dem` прямо в окно приложения или загрузка по прямому пути.
   - Автоматическое определение списка всех игроков (ник, `SteamID64`, команда `CT`/`T`, слот камеры `spec_player #1..#10`, статистика K/D/HS).
2. **Таблица моментов выбранного игрока с чекбоксами**:
   - **Авто-группировка одним кликом**: мультикиллы (`2K`, `3K`, `4K`, `ACE`) и выигранные клатчи (`1v1`..`1v5`).
   - **Все киллы**: раунд, время в раунде (`MM:SS`), тик, оружие, теги (`HS`, `Дым`, `Вслепую`, `NoScope`, `Прыжок`, `Прострел`), имя жертвы, индивидуальные отступы **До** (по умолчанию `2.0` с) и **После** (по умолчанию `2.0` с).
   - **Авто-слияние соседних киллов**: киллы в одном раунде с паузой `< 5 сек` автоматически объединяются в единый клип (от `первый_килл - До` до `последний_килл + После`).
   - **Все смерти**: раунд, время в раунде, кем убит (`attacker`), оружие, хедшот и чекбокс **«Показать от лица убийцы»** — переключает камеру (`spec_mode 1; spec_player <attacker_slot>`) на POV убийцы от `(тик смерти - N сек)` до `(тик смерти + M сек)` (по умолчанию `N = 4.0`, `M = 1.5`).
3. **Запись всех клипов за один запуск CS2 и склейка в MP4**:
   - **Режим HLAE (`AfxHookSource2`)**: генерация расписания `mirv_cmd addAtTick` + прямая запись потока `mirv_streams record screen` в `ffmpeg` + фильтрация киллфида `mirv_deathmsg`.
   - **Режим без HLAE (`netcon_capture`)**: запуск `cs2.exe -insecure -sw -netconport 2121`, управление камерой и тиками по локальному TCP-сокету и захват каждого клипа через `ffmpeg` (`gdigrab`).
   - **Быстрый тест пайплайна (`simulation`)**: мгновенная сборка тестового MP4 через `ffmpeg` без запуска CS2.
4. **Пост-обработка через FFmpeg**:
   - Прямая склейка (`concat`) или плавный кроссфейд `0.2 сек` (`xfade` + `acrossfade`).
   - Наложение фоновой музыки (`.mp3` / `.wav`) с регулировкой громкости.
   - Автоматический выбор аппаратного энкодера `h264_nvenc` (если доступен на видеокарте NVIDIA) или `libx264`.

## Быстрый старт

### 1. Запуск графического интерфейса (UI)
Дважды кликните по `run.bat` или выполните:
```powershell
python app.py
```
Откроется окно приложения (`http://127.0.0.1:8765`).

### 2. Использование из командной строки (CLI)
Проверить окружение (`CS2`, `FFmpeg`, `HLAE`, `NVENC`):
```powershell
python cli.py --check-env
```

Спарсить демку и вывести таблицу игроков, мультикиллов, клатчей, киллов и смертей:
```powershell
python cli.py samples\test_demo.dem
```

Собрать тестовый мувик из 5 киллов и 2 смертей (1 от лица убийцы) в один MP4:
```powershell
python cli.py samples\test_demo.dem --render-test --backend simulation --crossfade
```

## Конфигурация (`config.json`)

Все настройки хранятся в едином файле `config.json` (создаётся автоматически при первом запуске с авто-поиском `cs2.exe` в библиотеках Steam, `ffmpeg.exe` и `HLAE.exe`). При отсутствии HLAE его можно скачать автоматически одной кнопкой в окне **«⚙️ Пути и окружение»**.
